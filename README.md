## Run it

```sh
python3 draw.py
python3 main.py
```

`draw.py` renders `entry.png` (1024×1024, under 1 MiB) with Pillow; `main.py` copies it to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR`).
